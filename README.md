# La Huerta

App para pasar del PDF de respuestas del formulario semanal a las tres cosas que
hacen falta: qué cosechar, qué armar y qué cobrar.

**Se usa acá:** https://chantigym.github.io/la-huerta

## Qué hace

1. **Lista** — soltás el PDF que exportás del Google Sheet de respuestas (o el CSV).
2. **Revisar** — muestra lo que entendió y marca lo que conviene mirar.
3. **Cosechar** — qué levantar y qué pedirle a cada proveedor, por familia.
4. **Armar** — un paquete por persona, por punto de retiro, con la pesada.
5. **Cobrar** — el mensaje de cada cliente listo para WhatsApp, y el balance.
6. **Me deben** — quién pagó, quién quedó debiendo, y el saldo que se arrastra.

## Dónde quedan los datos

En el navegador de cada persona, y en ninguna otra parte. No hay servidor, no
hay cuentas y no se sube nada a internet: acá sólo vive el programa. Para pasar
los datos de una computadora a otra está *Respaldo*, en la última pantalla.

## Anda sin internet

Se instala desde el navegador ("Instalar" o "Agregar a pantalla de inicio") y
después abre sin señal, que es como se usa en el campo.
